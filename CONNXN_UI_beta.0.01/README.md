# CONNXN UI

Чистая локальная оболочка для работы с изображениями, видео, референсами,
canvas-воркфлоу и upscale.

Этот комплект специально собран пустым. В нем нет сохраненного профиля, API
ключа, аватарки, истории чатов, загруженных файлов, генераций, воркфлоу,
промптов или приватных ссылок.

## Быстрый запуск

### macOS

Дважды нажмите `CLICK ME.command`.

Если macOS заблокирует запуск, нажмите по файлу правой кнопкой, выберите Open
или Открыть и подтвердите запуск. Пока приложение используется, окно терминала
нужно держать открытым.

### Windows

Дважды нажмите `CLICK ME.bat`.

Пока приложение используется, окно консоли нужно держать открытым.

## Что нужно

- Node.js 20 или новее.
- KIE API key для реальной генерации.
- Опционально: `ffmpeg` для canvas/video-инструментов, которые извлекают,
  обрезают или меняют размер медиа.

При первом запуске лаунчер сам установит зависимости приложения.

## Локальные данные

При первом запуске приложение создаст в этой же папке локальные приватные файлы:

- `.connxn/` хранит профиль, чаты, загруженные ассеты, генерации и локальные
  данные воркфлоу.
- `.env.local` хранит KIE API key как `KIE_API_KEY`.

Эти файлы игнорируются и не входят в чистый комплект.

## Ручной запуск

```bash
npm install
npm run dev
```

После этого откройте локальный адрес из терминала, обычно:

```txt
http://127.0.0.1:4173
```
