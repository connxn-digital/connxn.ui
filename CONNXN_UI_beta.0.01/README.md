# CONNXN UI

Локальная оболочка для работы с API-агрегаторами: изображениями, видео, референсами, canvas-воркфлоу и upscale.

Само приложение абсолютно бесплатное. Я не продаю доступ, не беру комиссию и не получаю никакой выгоды с ваших платежей. Все деньги, которые вы тратите на генерации, вы платите напрямую KIE за использование их API. Я никак не связан с KIE финансово, не нахожусь с ними в доле и ничего с ваших пополнений не получаю.

Я сделал эту оболочку в первую очередь для собственного удобства и просто решил поделиться ей с другими.

## Перед запуском

Для реальной генерации необходимо сначала зарегистрироваться в KIE, получить KIE API key и пополнить баланс аккаунта KIE.

Без API ключа интерфейс можно запустить локально, но функции, требующие реальной генерации через API, работать не будут.

## Быстрый запуск

### macOS

Дважды нажмите `CLICK ME.command`.

Если macOS заблокирует запуск, нажмите по файлу правой кнопкой, выберите Open или Открыть и подтвердите запуск. Пока приложение используется, окно терминала нужно держать открытым.

### Windows

Дважды нажмите `CLICK ME.bat`.

Пока приложение используется, окно консоли нужно держать открытым.

## Что нужно

- Node.js 20 или новее.
- KIE API key с пополненным балансом для реальной генерации.
- Опционально: `ffmpeg` для canvas/video-инструментов, которые извлекают, обрезают или меняют размер медиа.

При первом запуске лаунчер сам установит зависимости приложения.

## Локальные данные

При первом запуске приложение создаст в этой же папке локальные приватные файлы:

- `.connxn/` хранит профиль, чаты, загруженные ассеты, генерации и локальные данные воркфлоу.
- `.env.local` хранит KIE API key как `KIE_API_KEY`.

## Ручной запуск

npm install  
npm run dev

После этого откройте локальный адрес из терминала, обычно:

http://127.0.0.1:4173
