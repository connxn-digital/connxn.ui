# connxn.ui

**connxn.ui** — локальная оболочка для работы с API-агрегаторами и AI-моделями для генерации изображений, видео, работы с референсами, canvas-воркфлоу и upscale.

Я сделал этот проект в первую очередь для себя — хотелось иметь один удобный интерфейс для работы с разными моделями и API без постоянного переключения между сервисами и сайтами.

Со временем решил выложить его в открытый доступ, чтобы им могли пользоваться и другие.

Сам **connxn.ui полностью бесплатный**. Я не беру комиссию с генераций, не продаю доступ и не получаю процент от платежей API-провайдерам. Все расходы на генерации пользователь оплачивает непосредственно выбранному API-сервису.
