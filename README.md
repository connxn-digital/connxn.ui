# connxn.ui

**connxn.ui** — локальная оболочка для работы с KIE API и AI-моделями для генерации изображений, видео, работы с референсами, canvas-воркфлоу и upscale.

Я сделал этот проект в первую очередь для себя — хотелось иметь удобный интерфейс для работы с генерациями и всем связанным с ними в одном месте.

Со временем решил выложить его в открытый доступ, чтобы им могли пользоваться и другие.

Сам **connxn.ui полностью бесплатный**. Я не беру комиссию с генераций, не продаю доступ и не получаю процент от платежей в KIE. Все расходы на генерации пользователь оплачивает непосредственно KIE.
